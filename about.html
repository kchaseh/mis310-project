PZ Enhancer by Keaton C. Hornsby is a website project for the class MIS 310: Web Page Development Languages instructed by Dr. Kevin D. Matthews at the University of North Carolina Wilmington. The website is used to enhance user experience in the video game "Project Zomboid" developed by The Indie Stone. Since the game is primarily played through the digital platform Steam, the website is tailored for users that play Project Zomboid on Steam. Using Steams community mods, the websites goal is to aid the user in creating a list of mods that the user will implement into the game. Thank you for visiting the page!
